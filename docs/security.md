# セキュリティ境界

初期Serverは127.0.0.1で待ち受けるローカル用途です。Origin付きの変更要求はlocalhost／127.0.0.1のHTTPのみ許可します。認証・複数ユーザー・外部公開向けの強化は未実装です。

外部取得は既知のProviderホストのHTTPSへ限定し、Redirectを追跡しません。接続と本文取得には期限、宣言サイズとストリーム実サイズには上限があります。glTF内の相対ファイルは公式DownloadOptionのresourcesと照合します。親ディレクトリ参照・絶対パス・任意URL・許可外形式を拒否します。ZIPは未対応として拒否します。

LocalAssetStorageは保存先を検証し、.data外への書込を防ぎます。読込ProjectはZodで検証してから置き換え、GLBの実行参照はServer内パスに制限します。サムネイルSVGは検証済み数値の頂点のみから生成し、入力テキストを埋め込みません。

ダミーAIは型付きCommandのみを返します。有料APIへの接続や任意コード実行の経路はありません。ブラウザーへ秘密キーを渡しません。処理Jobの永続化・堅牢な実Worker隔離は将来拡張です。
