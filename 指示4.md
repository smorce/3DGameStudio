# 実装依頼

あなたはThree.js、TypeScript、ブラウザ3Dゲーム、
低ポリゴン3Dモデリング、ゲーム向け視覚設計に詳しい
シニアゲームエンジニアです。

対象Repository：

https://github.com/smorce/3DGameStudio

対象Branch：

feat/machine-placement-system

必ずこのBranchの最新HEADを取得してから作業してください。


==================================================
1. 今回の目的
==================================================

Machine StudioのMachine Partのうち、

- Hinge（UI表示：関節）
- Thruster（UI表示：ジェット）

が現在ほぼ立方体として表示されています。

これを、

「子どもが見ただけでも、
 何をするパーツなのか想像できる形」

へ変更してください。


Hinge：

「ここを軸に回る部品」

だと見た目から分かること。


Thruster：

「こちらから噴射して、
 反対方向へマシンを押す部品」

だと見た目から分かること。


写実的なモデルは不要です。

現在のMachine Studioの、

- シンプル
- カラフル
- 低ポリゴン
- 玩具のように分かりやすい

という見た目に合わせてください。

4. Part Visual Factoryを作る
==================================================

Machine Partの外見生成処理を
Renderer本体から分離してください。


推奨：

createPartVisual(
  part: Part,
  options?: PartVisualOptions
): THREE.Group


または同等のAPI。


例：

packages/renderer-three/src/part-visuals.ts


責務：

Part Definition
↓
Three.jsの見た目を生成


最低限：

Panel
Block
Wheel
Motor
Steering
Hinge
Thruster
Wing

を受けられること。


ただし今回、
既存Partすべてを再デザインする必要はありません。


既存形状は維持して、

Hinge
Thruster

だけ専用形状を追加してください。


==================================================
5. Transformの責務
==================================================

createPartVisual()内部では、

World Position
World Rotation
World Scale

を適用しないでください。


Factoryは、

Partのローカル座標内の見た目

だけを生成する。


呼び出し側で、

visual.position
visual.rotation
visual.scale

を適用してください。


これにより、

通常表示
Placement Ghost
Play Mode

で同じVisualを安全に再利用できる構造にする。


==================================================
6. Hingeのデザイン
==================================================

Hingeは、

「機械式の回転関節」

に見える形にしてください。


推奨構成：

Hinge Group

├─ 中央回転ピン
│   CylinderGeometry
│
├─ 回転ピン外周
│   CylinderGeometry
│
├─ 左ブラケット
│   BoxGeometry
│
├─ 右ブラケット
│   BoxGeometry
│
└─ 必要なら軸キャップ
    CylinderGeometry


イメージ：

       ┌─────┐
       │     │
   ┌───●━━━━●───┐
   │    回転軸    │
   └─────────────┘


重要：

「四角い箱に模様を付けた」
だけにしない。


中央に明確な円筒軸を持たせる。


==================================================
7. Hingeの軸
==================================================

現在のMachine System / Joint設計との
方向を一致させてください。


Hingeの回転ピンは、

LOCAL X AXIS

に沿わせる。


つまり概念的には：

-X ←━━━━●━━━━→ +X


Three.jsのCylinderGeometryは
標準状態ではY方向が長手方向なので、

必要なRotationを適用し、

CylinderをX軸方向へ寝かせてください。


見た目の回転軸と
Rapier Joint Axisが一致していることを
必ず確認してください。


==================================================
8. Hingeの配色
==================================================

Primary：

part.visual.color

を使用する。


Secondary：

暗めの金属色。


例：

ブラケット
→ part.visual.color

中央ピン
→ dark metallic gray

軸キャップ
→ light metallic gray


ただし固定色だけにして、

StudioのColor変更機能を壊さない。


part.visual.colorを変更すると、
Hingeの主要部分の色も変化すること。


==================================================
9. Hingeのサイズ
==================================================

現在のPart.physics.sizeを基準にする。


固定された0.6だけを前提にしすぎないこと。


例：

const [sx, sy, sz] = part.physics.size;


そこから、

pinLength
pinRadius
bracketWidth
bracketHeight

を割合で決める。


VisualがColliderから極端にはみ出さないこと。


Physics Colliderは今回変更しなくてよい。


==================================================
10. Thrusterのデザイン
==================================================

Thrusterは、

「小型ロケットエンジン」

のような形にしてください。


推奨構成：

Thruster Group

├─ 円筒Engine Body
│
├─ Front Cap
│
├─ Nozzle
│   末広がりCylinder
│
├─ Nozzle Rim
│   TorusGeometry
│
└─ Nozzle Inner
    発光Material


イメージ：

+Z                           -Z

前                            排気

 ┌─────────┐
 │ ENGINE  │
 └─────────┘╲
              ╲
               ╲____
                 ◎


現在の立方体とは
明確にシルエットを変えること。


==================================================
11. Thrusterの方向は非常に重要
==================================================

現在のPhysicsでは、

Thruster Forceは

LOCAL +Z

方向です。


したがってVisualも必ず、

推進方向：

LOCAL +Z


排気方向：

LOCAL -Z

としてください。


概念：

              FORCE

               +Z
                ↑
                │

       [ THRUSTER ]

                │
                ↓

               -Z
              NOZZLE
              EXHAUST


これを絶対に逆にしない。


==================================================
12. Thruster Body
==================================================

Engine Bodyは円筒形にする。


CylinderGeometryを使ってよい。


ただしCylinderGeometryの標準長手方向と、
ThrusterのLOCAL Z方向は異なるので、

円筒をZ軸方向へ向ける。


Bodyは、

シンプルな円筒
+
前部キャップ

程度でよい。


==================================================
13. Thruster Nozzle
==================================================

ノズルは、

前側が細く、
排気側が太い

末広がり形状にしてください。


CylinderGeometryの、

radiusTop
radiusBottom

を変えることで作ってよい。


LOCAL -Z側が
大きく開くこと。


概念：

BODY

──────┐
      │
──────┘╲
        ╲
         ╲____
          -Z


単なるConeを貼り付けるだけでもよいが、
可能ならFrustum状のノズルを優先する。


==================================================
14. Nozzle Rim
==================================================

排気口の端に、

TorusGeometry

などでリングを付ける。


これにより、
遠目でもジェットだと認識しやすくする。


ノズル内部は、

dark gray

または

near black

にする。


==================================================

==================================================

排気口内部に小さな発光部を入れてよい。

現在のUIに合う色にする。


ただし常時巨大な炎を表示しない。


今回のScopeでは、

まず、

==================================================
19. Ghost Material
==================================================

Ghostでは、

同じGeometry
同じ形状構成

を使いながら、

Materialだけ、

transparent = true
opacity ≈ 0.3〜0.4
depthWrite = false

などへ変更する。


複数MaterialからなるHinge / Thrusterでも、
すべてGhostとして適切に透過すること。


通常VisualとGhost Visualで
Geometry生成ロジックを二重に書かない。

「立方体ではなくなった」

だけではありません。


Hingeを見た子どもが、

「ここがくるくる回りそう」

と説明なしでも感じられること。

見た目の分かりやすさのために
既存のPhysicsやPlacement Systemを
壊してはいけません。


中身の仕組みと、
外から見える形が一致していること。


では最初に、

- 現在のMachine Part描画箇所
- Ghost描画箇所
- Hinge Joint Axis
- Thruster Force Axis
