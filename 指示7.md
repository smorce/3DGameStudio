1. 現在地点
==================================================

Starter Plane / Boatの形状はかなり改善済みです。

現在のPlaneは概ね、

- 5枚程度の中央胴体
- 左右主翼

- 垂直尾翼

Starter Planeは現在のIntegration Test上、

↓

↓

現在のBoatは概ね、

を持つCatamaran型になっています。

外観は現在の方向を維持してください。


==================================================
2. 現在残っている問題
==================================================

問題A：

PlaneもBoatも基本的に直進しかできません。


現在Thrusterはすべて、

throttle * actuator.motorTorque

で同一出力しています。

steering入力はThrusterへ使われていません。


問題B：

Boatが水へ深く沈みすぎています。


現在の浮力は概念的に、

buoyantForce
≈
part.physics.mass * g * depthFactor

となっており、

「そのPart自身の質量」

を浮力の基準にしています。


これは船全体を浮かせる物理として不適切です。


今回、

A. 差動推力による旋回
B. 排水体積による浮力

へ修正します。

==================================================
4. Plane / Boat共通：差動推力
==================================================

左右に離れて配置されたThrusterを使い、

A / D入力によって左右の推力に差を付けます。


概念：

         FRONT +Z

             ↑

 left thruster      right thruster
      ↑                    ↑
      │                    │

 steering
      ↓

左右推力差
      ↓

重心まわりのYaw Moment
      ↓

旋回


RigidBodyへYaw Torqueを直接加えてはいけません。

既存の、

body.addForceAtPoint()

によって、
Thruster自身のWorld PositionへForceを加える方式を維持します。


==================================================
5. 一般化されたThruster Steering Mixer
==================================================

Starter Plane / Boatだけを特別扱いしないでください。

Thrusterを持つRigidBodyに対して利用できる、

一般的なThruster Steering Mixer

として実装してください。


おすすめ：

同じRigidBodyに固定されている、
前方向を向いたThruster群を取得する。

それぞれについて、

RigidBody / Machine座標系での
横方向位置 X

を調べる。


例：

left:
x < 0

right:
x > 0


横方向への距離を使って、
steering寄与を決めます。


概念：

maxLateralOffset
=
max(abs(thrusterLocalX))


normalizedSide
=
thrusterLocalX / maxLateralOffset


steeringContribution
=
steering
* THRUSTER_STEERING_MIX
* normalizedSide


そしてThruster commandを、

throttleとsteeringContribution

から計算してください。


==================================================
6. 推奨Mixer
==================================================

まずは次を初期案にしてください。


base = clamp(throttle, -1, 1)

steeringAmount =
clamp(steering, -1, 1)

command =
base
+
steeringAmount
* abs(base)
* THRUSTER_STEERING_MIX
* normalizedSide

command = clamp(command, -1, 1)


ただし左右方向がUI操作と逆になる場合は、
符号をテストで確認して修正してください。


重要：

Aキー
→ 左へ旋回

Dキー
→ 右へ旋回

となること。


コードを読んだ推測だけで符号を決めず、
Integration Testで確認してください。

==================================================

==================================================
18. Boat浮力を作り直す
==================================================

今回最も重要な変更の一つです。


現在の、

part.physics.mass

を基準にした浮力計算を廃止してください。


浮力は、

押しのけた水の重量

から計算します。


基本式：

Buoyant Force
=
fluidDensity
*
gravity
*
displacedVolume


水について：

WATER_DENSITY = 1000 kg/m³

を基本値としてください。


==================================================
19. Buoyancy Partの体積
==================================================

metadata.buoyancy === 1

のPartを、

密閉された浮力体

として扱います。


Panelについて、

実寸法：

sizeX
sizeY
sizeZ

から、

volume =
sizeX * sizeY * sizeZ

を計算してください。


transform.scaleが影響するPartであれば、
実際のWorld寸法を反映してください。


Panelは現在scale固定なら、
その仕様に従ってください。


==================================================
20. 部分水没
==================================================

Partが、

完全に水上
→ submergedFraction = 0

半分水中
→ 0 < submergedFraction < 1

完全水没
→ submergedFraction = 1

となる必要があります。


displacedVolume
=
partVolume
*
submergedFraction


としてください。


==================================================
21. Panelの水没率
==================================================

水平Panelについては、

Panel上端
Panel下端
Water Height

から水没率を求められます。


ただしBoat最前部など、
TiltされたPanelも将来あり得ます。


そこで、

World Rotationを考慮した
おおよその垂直Half Extent

を求めてください。


推奨近似：

Partの3本のLocal AxisをWorldへ回転し、

verticalHalfExtent =
0.5 * (
    abs(axisX.y) * sizeX
  + abs(axisY.y) * sizeY
  + abs(axisZ.y) * sizeZ
)


bottomY =
centerY - verticalHalfExtent

topY =
centerY + verticalHalfExtent


submergedFraction =
clamp(
    (waterHeight - bottomY)
    /
    max(topY - bottomY, epsilon),
    0,
    1
)


これは厳密な回転Boxと水面の交差体積ではありませんが、
今回のStarter Boatには十分な近似です。


正確なPolyhedron clippingは今回不要です。


==================================================
22. Buoyancy Force
==================================================

各Buoyancy Partについて、

displacedVolume =
volume * submergedFraction


buoyantForceMagnitude =
WATER_DENSITY
* gravityMagnitude
* displacedVolume


上向きForce：

[0, buoyantForceMagnitude, 0]


を作ります。


gravityについては、
Project設定と矛盾しないようにしてください。


通常は、

abs(project.settings.gravity[1])

を使う方法で構いません。


固定値9.81を複数箇所へ埋め込まないでください。


==================================================
23. 浮力はForceとして加える
==================================================

今回、

buoyancyをapplyImpulse()で実装しないでください。


Rapierの、

addForceAtPoint()

を使用してください。


理由：

浮力は固定Stepごとに働く連続Forceだからです。


値はN単位のForceとして扱い、

* dt

してImpulseへ変換しないでください。


==================================================
24. 浮力の作用点
==================================================

浮力はRigidBody中心へまとめて加えてはいけません。


各Buoyancy Partの、

World Position

へ、

addForceAtPoint()

してください。


概念：

左Ponton
     ↑ buoyancy

          COM

                 ↑ buoyancy
             右Ponton


こうすることで、

Boatが右へ傾く
↓
右Pontonが深く水没
↓
右側の浮力増加
↓
復元Moment発生

という挙動を自然に作ります。

を加えています。
