指示4.md の実装を完了しました。Hinge / Thrusterの専用Visual、通常表示とPlacement Ghostの共通化、軸方向テスト、Visual Evidenceを追加しました。

作業ブランチは `feat/part-visuals-hinge-thruster` です。指定ブランチ `feat/machine-placement-system` の最新HEAD `1b1047f` を基点に作業しました。

## 実装内容

Machine Partの外見生成を `packages/renderer-three/src/part-visuals.ts` の `createPartVisual(part, options)` に分離しました。

Factoryは以下のPart種別を受け付けます。

- Panel
- Block
- Wheel
- Motor
- Steering
- Hinge
- Thruster
- Wing

既存Partの基本形状は維持し、Wheelのハブ、PanelのシートもFactory内へ移動しました。PartのWorld Position、World Rotation、World ScaleはFactory内で変更せず、Renderer呼び出し側で適用しています。

## Hinge Visual構成

Hingeは、単純なBoxではなく機械式の回転関節として構成しました。

- `hinge-bracket-left`
- `hinge-bracket-right`
- `hinge-pin`
- `hinge-cap-left`
- `hinge-cap-right`

`hinge-pin` は `CylinderGeometry` をZ軸回転して、PartのLOCAL X AXISに沿わせています。ブラケットは `part.physics.size` の比率から寸法を決め、`part.visual.color` を主要色に使用しています。ピンは暗い金属色、キャップは明るい金属色です。

## Thruster Visual構成

Thrusterは小型ロケットエンジンとして構成しました。

- `thruster-body`
- `thruster-front-cap`
- `thruster-nozzle`
- `thruster-nozzle-rim`
- `thruster-emitter`

本体は円筒形で、前部キャップをLOCAL +Z側に配置しています。ノズルはLOCAL -Z側に配置し、`radiusTop` より `radiusBottom` を大きくした末広がり形状にしています。排気口にはTorusのリムと、弱い発光を持つエミッタを追加しました。

## Local Axis Convention

- Hingeの回転ピン: LOCAL X AXIS
- Thrusterの推進方向: LOCAL +Z
- Thrusterの排気口: LOCAL -Z

Thrusterの推進方向と排気方向は、既存PhysicsのConventionを変更せず、Factory内の意味のある `userData` とUnit Testで確認できるようにしています。

## Ghost Preview対応

通常VisualとGhost Visualは同じ `createPartVisual()` を使用します。Ghost時はGeometry構成を変えず、全MeshのMaterialだけを次の設定にします。

- `transparent = true`
- `opacity = 0.35`
- `depthWrite = false`

これにより、実体が専用形状なのにGhostだけBoxになる不一致をなくしました。CandidateのPosition / Rotationは既存のPlacement処理からGroupへ適用し、Preview PartのScaleも維持しています。

## Picking / Selection / Dispose

Part IDはFactoryの親Groupへ既存どおり設定しています。子Meshをクリックした場合も親Groupまで辿る既存Pickingを利用できます。Selection Outlineは新しい複合Visual全体を囲みます。

既存のRenderer `clear()` がGroup内を再帰走査してGeometry / MaterialをDisposeするため、通常VisualとGhostの再生成・破棄にも対応しています。

## Physicsへの影響

Physics、Collider、Hinge Joint方式、Thruster Force、Placement、Command、Schemaは変更していません。見た目だけを複数Meshへ変更し、既存の単純Colliderと既存Force方向を維持しています。

## 追加修正（2026-09-11）

前回報告後、部品の機能と見た目の一致を高めるため、以下を追加しました。

### Thrusterの接続方向

- Panel / Blockの左右の `jet-*` ConnectorへThrusterを接続すると、排気口のLOCAL -Zが親Connectorの外側を向くように配置。
- ThrusterのmountはLOCAL +Z側へ移し、ノズルと🔥が機体内部へ向かないように修正。
- Hingeの `hinge-output` へ接続するThrusterにも同じ方向決定を適用。
- 左右のJet ConnectorおよびHinge出力への接続方向をUnit Testで検証。

### Motorの専用Visual

Motorを立方体のBasic Visualから、機能が読み取れる専用Visualへ変更しました。

- 短い円筒形の `motor-body`
- 濃色の `motor-rear-cap` / `motor-front-cap`
- 銀色の `motor-output-shaft` / `motor-output-tip`
- 本体を固定する `motor-mount-left` / `motor-mount-right`
- 出力軸の向きを示す `outputAxis = LOCAL +Z`
- 作動中だけ出力軸付近で発光・回転する `motor-rotation-indicator`

編集画面ではインジケーターを消灯し、プレイ中に入力がある場合だけ軸付近を発光させます。Motorを関節の回転軸へ実際に関連付ける制御ロジックは今回の追加修正では変更していません。
