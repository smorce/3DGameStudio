==================================================
2. Sample World Catalogを新設
==================================================

8ワールドを

if / else
switch
EnvironmentPreset追加

だけで管理してはいけません。


新しく

packages/sample-worlds

を作ることを推奨します。


最低限以下を定義してください。


interface SampleWorldDescriptor {
  id: string;
  name: string;
  shortDescription: string;
  icon: string;
  tags: string[];

  recommendedMachine:
    | "car"
    | "plane"
    | "boat";

  sortOrder: number;

  buildProject(): Project;
}


ただしbuildProjectがNode専用処理や
Asset Factoryを直接呼ばない設計にしてください。

Sample World Definitionと
「Assetを準備してBakeする処理」は分離してください。


例:

SampleWorldCatalog
    ↓
World Project Draft
    ↓
Dummy Requirement Planner
    ↓
Asset Factory
    ↓
Bake
    ↓
Prepared Sample Project


==================================================
3. RuntimeとSample Contentを分離
==================================================

world-generator自身に

desertWorld()
snowWorld()
mountainWorld()
raceWorld()

を大量に直接追加するだけの設計は禁止です。


Engine:

packages/world-generator

Content:

packages/sample-worlds

へ分離してください。


world-generatorは

「World Designをどう生成するか」

だけ知ります。


sample-worldsは

「どんなWorld Designを作るか」

を持ちます。


==================================================
4. EnvironmentPresetを乱造しない
==================================================

既存

grassland
airfield
archipelago
toy-islands

との後方互換を維持してください。


新しいWorld Design系ワールド向けに、
必要なら

designed-world

という汎用Presetを1つ追加してください。


例:

preset: "designed-world"
design: <WorldDesign>


新規ワールドごとに

mountain
desert
snow
race
tropical

をEnvironmentPresetへ追加するのは禁止です。


BiomeとWorldは別概念として扱ってください。


既存toy-islandsは互換性のため
toy-islands presetを残して構いません。

新しいSample Worldは原則
designed-worldを利用してください。


==================================================
5. Biome Surface Profileを実装
==================================================

現在のWorld Design経路では、
地表色がarchipelago用の

water-bed
sand
grass
rock

に実質固定されています。

これを改善してください。


砂漠や雪山を実装するため、

Biome Surface Profile

を導入してください。


例えば:

interface BiomeSurfaceProfile {
  id: string;

  underwaterColor: string;
  shoreColor: string;

  lowlandColors: string[];
  highlandColor: string;

  rockColor: string;

  snowColor?: string;
  snowLine?: number;

  shoreMaxHeight: number;
  highlandMinHeight: number;
}


最低限:

temperate
grassland
tropical
alpine
desert
snow

を用意してください。


World Generatorは、

sampleBiome(x, z)

でBiomeを決定してから、

Biome Surface Profile

を参照して色を決定してください。


重要:

World Designを持つからといって

colorFor("archipelago")

へ強制的に流す現在の構造を解消してください。


==================================================
6. Biome Definitionは再利用可能に
==================================================

Biome定義をWorldごとにコピペしないでください。


例:

BiomeCatalog

temperate
tropical
alpine
desert
snow


World Design側は

biome: "desert"

のように参照します。


ただし、

保存済みWorldが将来勝手に見た目変更されない

ことも重要です。


次のどちらかを採用してください。

A.
Biome profile versionをWorld Build Manifestへ固定

または

B.
Bake時にresolved biome profileをManifestへ保存


どちらを採用したかDocumentへ明記してください。

==================================================
8. 前回レビュー指摘も同時に修正
==================================================

Sample World追加前に以下を修正してください。


--------------------------------
8-1. Worker generation context
--------------------------------

現在はWorkerへ送ったWorld Designを
オブジェクト参照でキャッシュしています。

同一オブジェクトをmutateした場合でも
更新を検出できるよう、

designFingerprint
または
designRevision

を使用してください。


World Design変更
    ↓
reload
    ↓
Worker generation-context更新

が確実に起きるようにしてください。


Test:

同じWorldDesign objectをmutate
↓
reload
↓
Worker生成結果が新Designを反映

を追加してください。


--------------------------------
8-2. Settlement
--------------------------------

現在SettlementはassetSlotを持っていますが、
Settlementから建物配置は実質生成されていません。

今回町を持つWorldが増えるため、
この曖昧さを解消してください。


推奨:

SettlementDefinition

- id
- center
- radius
- height
- buildingRules


buildingRules:

- assetSlot
- count / density
- minSpacing
- minDistanceFromRoad
- scaleRange
- rotationMode


例:

buildingRules:
  - assetSlot: building.village.house
    count: 8
    minSpacing: 12


既存v6 Settlement.assetSlotは
v7 migrationでbuildingRulesへ変換してください。


==================================================
9. Road Definition拡張
==================================================

レースアイランド用に必要なら、

RoadDefinitionへ

closed?: boolean

を追加してください。


closed = trueなら
Spline終端から始点へ滑らかにつなぐこと。


Chunk境界、
Road Terrain Conform、
sampleRoadInfluence

でも閉ループが成立するようにしてください。


既存Roadは

closed = false

として完全互換にしてください。

だけで開始画面から遊べるようにしてください。

    toy-islands.json

    shared demo asset library

で決定的に作成し、
