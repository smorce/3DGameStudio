あなたはThree.js、React、TypeScript、3Dエディター、
ゲーム向けスナップ配置、初心者向けUXに詳しい
シニアゲームエンジニアです。

対象Repository：

https://github.com/smorce/3DGameStudio

対象Branch：

feat/world-runtime-foundations

必ずこのBranchの最新コードを取得・確認してから作業してください。

==================================================
1. 今回の目的
==================================================

Machine StudioのLEVEL 1「つくる」に、

子どもでも説明書なしで使える
「パーツ選択 → 光っている場所を押すだけ」
のマシン組み立てシステムを実装してください。

今回の最重要UXは、

「置けば動く」

です。


ユーザー体験：

1. 「タイヤ」を選ぶ

2. 現在そのタイヤを取り付け可能な場所だけが
   3D Viewport内で光る

例：

       ●

   ● [板] ●

       ●

3. 光っている場所を1か所クリックする

4. その場所へタイヤが自動的にSnapして配置される

5. 内部では、

   - Part生成
   - Position決定
   - Rotation決定
   - Connector接続
   - Joint設定
   - Collider設定
   - Physics設定
   - Friction設定
   - Wheelなら前輪/後輪判定
   - Drive判定
   - Steering設定
   - Control設定

   など必要な処理を自動的に行う

6. ユーザーから見える操作は、

   「タイヤを付けた」

   だけにする

7. 配置完了後は他の光る候補をすべて消す

8. 今置いたPartだけを選択状態にする

9. その場で、

   [↻ 回す]
   [反対向き]
   [つけ直す]
   [コピー]
   [消す]

   などの簡単操作ができる

これを実装してください。

==================================================
6. Attachment Candidate
==================================================

machine-systemへ、

「現在このPartをどこへ付けられるか」

を計算する純粋ロジックを追加してください。


推奨API：

findAttachmentCandidates(
  machine: Machine,
  kind: Part["definitionId"]
): AttachmentCandidate[]


概念型：

interface AttachmentCandidate {
  id: string;

  parentPartId: string;
  parentConnectorId: string;

  childConnectorId: string;

  position: Vec3;
  rotation: Vec3;

  axis: Vec3;

  connectionType: "fixed" | "revolute";
}


重要：

Renderer自身に
Machine接続ルールを判断させないでください。

Rendererは、

「渡された候補を表示する」

だけにする。

接続可能性の判定は
machine-systemに置く。

==================================================
10. part.attach Command
==================================================

ユーザーがCandidateをクリックした操作を、

複数の低レベルCommandへ
UIから直接分解しないでください。


推奨：

part.attach

Commandを追加する。


例：

{
  type: "part.attach",

  machineId,
  kind: "Wheel",

  parentPartId,
  parentConnectorId,

  childConnectorId,

  rotationStep: 0
}


または同等の設計。


実際のPart IDをCommand生成時に確定する設計でもよい。


重要なのは、

Undoを1回押したら、

「今付けたタイヤ」

に関する、

- Part
- Connection
- 自動Metadata

が一括して元に戻ること。


既存CommandBusの思想を壊さないこと。

16. Rotation
==================================================

配置したPartについて、

LEVEL 1では数値Rotationを見せない。


ボタン：

[↻ 回す]


を押すたび、

有効な離散角度を循環させる。


基本：

0°
90°
180°
270°


ただしConnector AxisやPart種別によって
適切な回転軸を選んでください。


Wheelについては、

意味のない方向へ回して
Physicsを壊さないこと。


LEVEL 1では、

「回転X 1.570796」

のような表示は禁止。

18. つけ直す
==================================================

選択中Partへ、

[◎ つけ直す]

を追加してください。


押したら、

そのPartに対して現在利用できる
Attachment Candidateを再表示する。


重要：

ユーザーが新しいCandidateを選ぶまで、
現在のPartを失わないこと。


悪い実装：

↓
現在Part削除
↓
ユーザーCancel
↓
Partが消えている


は禁止。


理想：

現在位置を保持
↓
Reattach Mode
↓
Candidate選択
↓
1 Command / 1 Undo単位で接続先変更


必要なら、

part.reattach

Commandを追加してください。

45. 最重要原則
==================================================

この機能の成功基準は、

コードが汎用的であることだけではない。


小学生が、

「タイヤをつけたい」

↓

「タイヤを押した」

↓

「光ったところを押した」

↓

「タイヤがついた」

と理解できること。


内部の複雑さを
ユーザーへ漏らさないこと。


Machine Studioは、

中身は本格的でも、
LEVEL 1では玩具のように簡単

であること。
